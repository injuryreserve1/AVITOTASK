## 🐳 Метод 1: Запуск в Docker-среде (Рекомендуемый)

Используйте **Docker Compose** для сборки и запуска клиента и сервера в изолированных контейнерах.

### 1\. Первичная сборка и запуск

Эта команда собирает образы из Dockerfile, устанавливает все зависимости и запускает оба сервиса. Используйте ее при первом запуске или после изменения **Dockerfile** или файлов **`package.json`**.

```bash
docker compose up --build
```

### 2\. Повторный запуск

Используйте эту команду для быстрого перезапуска контейнеров, если образы уже собраны.

```bash
docker compose up
```

### Доступ

  * **Клиент (Frontend):** `http://localhost:3000`
  * **Сервер (Backend):** `http://localhost:3001`

## 💻 Метод 2: локальный обычный запуск

Этот метод подходит для активной разработки и отладки, обеспечивая горячую перезагрузку (Hot Reload).

### 1\. Запуск Клиента (Frontend)

Клиентский код находится в корневой директории.

```bash
# Установка зависимостей клиента
npm install

# Запуск клиента в режиме разработки
npm run dev
```

### 2\. Запуск Сервера (Backend)

Серверный код находится в папке `tech-int3-server/`.

```bash
# Переход в директорию сервера
cd tech-int3-server

# Установка зависимостей сервера
npm install

# Запуск сервера в режиме разработки
npm run dev
```
